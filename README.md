TorusNet — Directional Network Protocol
TorusNet is an experimental internet protocol based on a directional architecture rather than traditional cryptography.
It introduces the concept of a private torus, a non‑transmissible geometric structure used to validate coherence, generate movement vectors, and secure communication through topology instead of mathematical encryption.

The project is fully documented and archived on Zenodo, the official research repository operated by CERN and OpenAIRE.

TorusNet, directional protocol, private torus, topology security, quantum-safe, photonic-ready
